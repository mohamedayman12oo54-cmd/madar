

## لوحة المعلم (v2)
صفحات اللوحة كلها حقيقية (لا placeholders): نظرة عامة، الطلاب، المجموعات والمواعيد، الجلسات، الحضور والتسميع (الجلسة السريعة)، التقييم الشهري، المدفوعات، المحتوى، المساعد، الإشعارات، الإعدادات. لكل صفحة نافذة «ما وظيفة هذه الصفحة؟» (`src/dashboard/pageInfo.js`).

- `npm test` يشغّل اختبارات الـ phone/video/poll/api/nav + **اختبار رسم (render smoke)** يفتح كل صفحات اللوحة في jsdom بـ API وهمي ويفشل لو أي صفحة انهارت (صفحة بيضاء). قواعد الهاتف في `src/lib/phone.js` مرآة لـ `backend/accounts/phones.py` — عدّل الاثنين معًا عند إضافة دولة.
- الإنتاج: `VITE_API_URL` **يجب** أن يكون `https://…` وإلا يتوقف التطبيق عمدًا.
- التقرير الأمني والمطابقة للوثائق: `../madar-backend/SECURITY.md` و`../CONFORMANCE.md`.


## لوحة الطالب (`/learn`)
مبنية للموبايل أولًا (شريط تبويب سفلي): الرئيسية • سجلّي (حضور/تسميع/دفع/تقييم) • الفيديوهات (+ «اختبرني») • اختباراتي • المساعد • الإشعارات • الإعدادات. بعد تسجيل الطالب واختيار المعلم يُحوَّل إلى `/learn`. لكل صفحة نافذة «ما وظيفة هذه الصفحة؟». اختبار الرسم (`npm test`) يفتح الصفحات الـ9 كطالب والـ12 كمعلم.
